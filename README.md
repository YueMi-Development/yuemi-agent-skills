Agent skills used and maintained by **YueMi Development** for AI coding assistants, covering Minecraft server development, game server infrastructure, toolchains, and plugin ecosystems.

## Installation

Install using the `skills` CLI:

```bash
# Install all skills from this repository
npx skills add https://github.com/YueMi-Development/yuemi-agent-skills

# Or install a specific skill
npx skills add https://github.com/YueMi-Development/yuemi-agent-skills --skill <skill-name>
```

## Structure

Each skill resides in its own directory under [`skills/`](skills/) and includes a `SKILL.md` specification with workflows, code patterns, and reference documentation.
